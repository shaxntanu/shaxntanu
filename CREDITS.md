## Data and automation

The contribution graph reflects GitHub contribution data. GitHub Actions runs the workflows that refresh the contribution visuals.

## Local Rust utility

The small Rust utility in <code>tools/readme-asset-check</code> checks that local image paths referenced by the README exist. Run it from the repository root: <code>cargo run --manifest-path tools/readme-asset-check/Cargo.toml</code>
