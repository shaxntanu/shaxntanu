## Featured Projects

### Zephyr Station

An ESP32 environmental monitoring station with seven sensors/modules, live OLED readings, SD-card data logging, RTC timestamps, threshold alerts, and a web dashboard.

[![Zephyr Station repository](https://img.shields.io/badge/Zephyr%20Station-Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/shaxntanu/Zephyr-Station)

### Energy Consumption Pattern Analysis

A PCA and K-Means pipeline for exploring daily electricity-use patterns.

[![Energy Analysis repository](https://img.shields.io/badge/Energy%20Analysis-Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/shaxntanu/Energy-Consumption-Pattern-Analysis-using-PCA-and-K-Means)
[![Web explorer](https://img.shields.io/badge/Web%20Explorer-Open-2563EB?style=flat-square&logo=vercel&logoColor=white)](https://energy-consumption-pattern.vercel.app)
[![Streamlit simulator](https://img.shields.io/badge/Streamlit-Simulator-FF4B4B?style=flat-square&logo=streamlit&logoColor=white)](https://energy-consumption-pattern-vqrh.streamlit.app)

### Jolt Locator

An Arceus Labs team project: an ESP32 GPS compass that points toward the nearest energy-drink store, with true-north heading, an OLED display, and GPS-status indicators.

[![Jolt Locator repository](https://img.shields.io/badge/Jolt%20Locator-Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Arceus-Labs/Jolt-Locator)
